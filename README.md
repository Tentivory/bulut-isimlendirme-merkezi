# Bulut Isimlendirme Merkezi

**T.C. Gokyuzu Isleri Genel Mudurlugu — Bulut Isimlendirme ve Tescil Dairesi** resmi yazilimi.

Bu proje, gokyuzundeki her sekli resmi evrak diliyle adlandirir. Amaci bilimsel degildir. Amaci, bir buluta bakip "koyun gibi" demek yerine "Mustesna Yatak Odasi Terligi Bulutu — Nimbus Dilekce" demektir. Cunku medeniyet budur.

## Neden var?

Cunku isimsiz bulut hukuken yoktur. Isimsiz bulut yagmur yagdiramaz, golge satamaz, sosyal medyada trend olamaz. Bu yazilim o eksikligi kapatir.

## Kurulum

Python 3 yeter. Baska hicbir sey istemez. Bagimliligi yoktur. Gururu vardir.

```bash
python3 bulut_tescil.py
```

Calistirdiginiz anda bir tescil belgesi basilir. Her calistirmada farkli bir resmi ad uretilir. Tekrarlanabilirlik bilimseldir; burasi bilim degil, dairedir.
